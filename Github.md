# Repositories

A repository  is a project folder stored on GitHub.
It contains:
	•	Source code
	•	README file
	•	Branches
	•	Commit history

It allows developers to store and manage project versions online.
#Branches

Branches allow developers to work on new features without affecting the main project.

Example:
	•	main
	•	feature/documentation
	•	feature/collab-update

Helps in parallel development.

#Pull Requests (PR)

Pull Request is used to:
	•	Propose changes
	•	Review code
	•	Discuss modifications
	•	Merge branches safely

Very important for team collaboration.



# Issues

Issues are used to:
	•	Report bugs
	•	Suggest features
	•	Assign tasks
	•	Track progress

You can assign issues to team members.



#Actions (CI/CD)

GitHub Actions automates workflows like:
	•	Testing code
	•	Building projects
	•	Deploying applications

It supports Continuous Integration & Continuous Deployment.

# Projects

GitHub Projects provides:
	•	Kanban boards
	•	Task tracking
	•	Workflow management

Helps manage software development tasks efficiently.
